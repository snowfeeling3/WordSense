## 基准

v1.0.4 额外验证：统一词库通过 SQLite backup 复制，完整性和数据校验通过，词条及文章目录设置保留；旧库清理后重启只打开新位置的同一个库；不覆盖目标已有库；配置写入失败保留原库且可继续编辑；配置目标丢失不创建空库；GUI 迁移保持正文及光标。最新 packaged-smoke.json、extracted-smoke.json 版本为 1.0.4，新增 shared database relocation and old-file cleanup、database path survives restart 检查。

使用 Qt offscreen 平台并显式载入本机 Segoe UI、Consolas、微软雅黑字体。通过真实 QTest 键盘事件测量同步输入与增量高亮，包括文本编辑事件的处理；不包含屏幕呈现和磁盘 I/O。多段落粘贴会额外补齐段落缩进，120,000 是原始剪贴板字符数。

高亮按文本块增量执行；极长单段落的成本随段落长度增长。这是当前 MVP 的已知性能边界。词典修改的全文刷新另走全局路径。强制终止进程可能丢失尚未自动保存的最后输入，正常关闭会等待持久化完成。

上述数据来自本机一次最终执行，不能视为其他硬件或实际屏幕延迟的保证。可运行命令重现并覆盖基准 JSON。
