# WordSense v1.0.5

## 简体中文

基于 v1.0.4 更新的本地英语写作编辑器。

- Ink Slate 墨蓝灰主题：分层背景、更清晰的文字与键盘焦点，保留四种词汇状态色。
- 单词、词义与理解程度增加常驻标签；突出保存操作，使用清晰的“文档”菜单按钮。
- 保留每日 Markdown、共享词库、目录迁移和全部键盘流程。
- 精简旧发布记录与验证产物，源码采用 MIT 许可证。

48 项自动化测试通过。Windows x64 安装包通过打包运行、异地解压与移除 Python 环境路径的验证。解压完整 ZIP 后运行 WordSense.exe，保留 _internal 文件夹。安装包未签名，不包含个人词库或文章。

## English

An update built on v1.0.4: Ink Slate colors, persistent vocabulary field labels, a prominent save action, visible keyboard focus and a clearly labeled document menu. Daily Markdown, shared vocabulary, migration and keyboard workflows are preserved.

All 48 tests pass. The portable Windows x64 package passes packaged and relocated execution checks without Python on PATH. Extract the complete ZIP and keep _internal beside WordSense.exe. The unsigned package includes no personal dictionary or articles. Application source is MIT licensed; third-party components retain their own licenses.
