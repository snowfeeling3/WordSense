# WordSense v1.0.4

## English

A local-first Windows English writing editor with a shared vocabulary database and instant understanding-level colors. This release includes the Everforest Dark Soft theme, three recorded levels, yellow unknown words, a searchable dictionary sidebar, daily Markdown files, configurable document/database paths and the WordSense book-shaped W icon.

Download `WordSense-v1.0.4-Windows-x64.zip`, extract the whole folder and run `WordSense.exe`. Python is included; keep `_internal` beside the executable. The package contains no personal documents or vocabulary. `WordSense-v1.0.4-Windows-x64.zip.sha256` provides the archive checksum.

48 automated tests pass. The packaged executable was also checked after relocation to another directory with Python/Conda removed from PATH, including database/document migrations and restart recovery. This is an unsigned portable Windows x64 build.

## 简体中文

本地优先的 Windows 英语写作编辑器，所有文章共用一个词库，并实时标记理解程度。包含 Everforest Dark Soft 主题、三种理解程度、黄色未知词、可检索词典侧边栏、每日 Markdown、自定义文档/词库位置和书页 W 图标。

下载 `WordSense-v1.0.4-Windows-x64.zip`，解压完整文件夹后运行 `WordSense.exe`。无需安装 Python，请保留 `_internal` 文件夹。分发包不含个人文章或词库，附 `.sha256` 校验文件。

48 项自动化测试通过；打包程序移到其他目录、移除 Python/Conda 环境路径后，也验证了词库/文档迁移及重启恢复。本版本为未签名的 Windows x64 免安装版。
